# ДЗ 6. Ускорение инференса

Замеры на H100 MIG 40 GB. Перед каждым замером очищал prefix cache и прогревал сервер

### Задержка при 120 RPM

| Конфигурация | Средняя, с | P90, с | Ускорение |
|---|---:|---:|---:|
| Бейзлайн | 6,619 | 8,981 | 1,000× |
| Лимит 32 последовательности | 6,699 | 9,138 | 0,988× |
| Лимит 8192 токена на батч | 6,612 | 8,958 | 1,001× |
| N-gram | 6,943 | 9,917 | 0,953× |

Лимит 8192 дал наименьшую среднюю задержку. Разница около 0,1% по одному замеру

### Спекулятивное декодирование

| RPM | P90 без спекуляции, с | P90 с n-gram, с |
|---:|---:|---:|
| 60 | 7,64 | 7,62 |
| 240 | 14,17 | 13,51 |
| 480 | 112,02 | 113,02 |

При 60 RPM разницы почти нет. При 240 RPM n-gram снизил P90. При 480 RPM оба варианта не справились с потоком запросов. [График](results/speculation.png)

### Предел нагрузки

Для варианта с лимитом 8192 токена на батч наибольшая проверенная нагрузка в пределах SLA составила **270 RPM** при P90 **13,85 с**. На следующей проверенной точке, 280 RPM, P90 достиг **18,02 с**. [График SLA](results/sla.png) · [Все замеры](results/measurements.csv)

Точную точку пересечения кривых и порог между 270 и 280 RPM не измерял
